> **یکپارچه‌سازی، سرعت حداکثری و کاهش ۴۰ برابری مصرف توکن در Antigravity، Cursor، VS Code و Claude.**

[English Documentation](README.md)

## 🎯 این پروژه چه مشکلی را حل می‌کند؟

ایجنت‌های هوش مصنوعی معمولی برای پیدا کردن یک تابع یا باگ، صدها خط خروجی `grep` را وارد حافظه چت می‌کنند. این کار باعث می‌شود:
1. توکن‌های شما به سرعت تمام شود و هزینه‌ها افزایش یابد.
2. پنجره کانتکست چت پر شده و مدل کدهای قبلی را فراموش کند.

با نصب این ابزار:
- موتور **XERJ** به عنوان مغز جستجو فعال می‌شود.
- تمام ایجنت‌ها به صورت **غریزی و خودکار** (بدون نیاز به یادآوری شما) جستجوها را هوشمند، سریع و با یک‌چهلم توکن انجام می‌دهند.
- **حافظه بین‌چتی (Memory Graph)** فعال می‌شود تا تصمیمات شما در چت‌های بعدی فراموش نشود.

## ⚡ نحوه نصب فوق‌سریع (۱ کلیک)

در ویندوز، **PowerShell (Run as Administrator)** را باز کنید و دستور زیر را اجرا کنید:

```powershell
irm https://raw.githubusercontent.com/taimazus/universal-ai-optimizer/main/setup-ai-optimizer.ps1 | iex
```

## 🌟 امکانات کلیدی

- **نصب کاملاً خودکار:** باینری XERJ را دانلود و متغیرهای PATH را تنظیم می‌کند.
- **اتصال جهانی MCP:** روی Antigravity، Cursor، VS Code و Claude Desktop به طور همزمان ست می‌شود.
- **پشتیبانی از پروژه‌های قبلی و آینده:** تمام پروژه‌های دسکتاپ و درایوهای دیگر را اسکن و خودکار ایندکس می‌کند.
- **هوک‌های سراسری گیت:** هر پروژه‌ای کلون یا جابه‌جا شود، با اولین سوییچ شاخه یا pull به صورت نامرئی ایندکس می‌شود.
